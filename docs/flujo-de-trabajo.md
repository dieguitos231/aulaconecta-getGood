# Comandos

## GIT COMMIT
# ¿Que nodo apareció y dónde quedo apuntando la rama?
-Al ejecutar git commit se crea una nueva registro y avanza en la rama main por lo que si ,el commit anterior era el 0 al ejecutar se crea el commit 1.
## GIT BRANCH 
# ¿Que se creó y sobre qué commit quedó ubicado?
- Si la rama esta en el MAIN git branch nombra ese commit para referencia y asi  no afectar el main.
## GIT CHECKOUT
# ¿Qué cambió al moverse a otra rama?
-Cambio la seleccion del commit  a la seleccion especifica ya sea el hash de un commit el nombre de una rama o el propio main.
## GIT MERGE 
# ¿Que historias de trabajo quedaron integradas?
-Quedan inetgradas el archivo seleccionado y se une al main.
