# AulaConecta -Plataforma Web Educativa
## Descripcion del proyecto
Es una plataforma web para consultar cursos,registrar personas interesadas y administrar contenidos.

## Problema que resuelve
La mala organizacion a nivel de desarrollo del proyecto que esta enfocado en una platafor educativa.

## Objetivo
Tener un plataforma web interactiva  en la cual su principal enfoque sea llamar la atencion de nuevos estudiantes y asi brindar conocimiento para su vida. 
## Alcance inicial
Tener una organizacion clara al momento de subir cambios,con el fin de tener un mejor flujo de trabajo y que cada integrante pueda subir cambios sin afectar a otro.
Diseñar una plataforma web que sea llamativa e interactiva para atraer nuevos estudiantes.

## Acuerdo de trabajo
1. Cada commit tiene que estar con un mensaje descriptivo de que cambios se realizaron o que se agrego.
2. Cada commit tiene que estar en una rama independiente a main.
3. Cada rama debe tener una palabra clave de que modulo afecta o seccion es.
4. Cada pull request sera revisado por los demas colaborados para dar un aval.
5. Se fusionara el commit cuando sea aprobado y se hallan hecho las respectivas pruebas con la version estable.

## Cinco criterios de calidad
1. La funcionalidad del codigo implementada cumple con los requisitos y no presenta errores durante su ejecución.
2. Todas las pruebas  se ejecutan sin fallos y si corresponde a la tarea acordada
El código fue revisado y aprobado
3. Al menos un colaborador del equipo realizó una revision de código y aprobo el Pull Request.
4. Cumple con los estandares del desarrollo de software.
5. No genera conflictos ni afecta la version estable.
6. El Pull Request está actualizado con la rama de destino y no tiene conflictos.
